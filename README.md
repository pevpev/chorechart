# ChoreChart — your first micro-product

A free printable chore-chart generator (the traffic magnet) plus a paid **Pro** download (the income). Everything is plain HTML/CSS/JS — no build tools, no server, no monthly costs.

Current features: weekly printable charts, age-based chore idea library, clickable done boxes with a progress bar, a creature companion powered by both streaks and points, unlockable creature outfits, a points-based reward shop, badge shelf, per-chore streaks, morning/bedtime routine printables, week templates, Spanish labels, Letter/A4 and portrait/landscape printing, an allowance calculator, emoji icons (Pro), printable coupons and star chart (Pro), multiple children (Pro), and offline use.

The free site is also installable as a web app (manifest.json + icon.svg).

The free page also includes a how-it-works section, example chart gallery, and FAQ to help convert visitors.

## What's here

| File | What it is |
| --- | --- |
| `index.html` | The free tool. This is what people use on your website. |
| `styles.css` | All styling. |
| `app.js` | All logic. Free/Pro behaviour is controlled by one flag. |
| `build.mjs` | Generates the single-file Pro version from the same source. |
| `ChoreChart-Pro.html` | **The product you sell.** Generated by `build.mjs`. |
| `GUMROAD_LISTING.md` | Ready-to-paste Gumroad description. |

**Do not upload `ChoreChart-Pro.html` to your public website or GitHub repo.** It is the paid product.

## Try it now

Double-click `index.html`. It opens in your browser, works offline, and saves changes in your browser.

To see the Pro version locally, double-click `ChoreChart-Pro.html`.

## Make it yours

1. Create a Gumroad account at https://gumroad.com.
2. Create a product named **ChoreChart Pro**, upload `ChoreChart-Pro.html`, set a price of $4 (or pay-what-you-want with a $3 minimum), and paste the copy from `GUMROAD_LISTING.md`.
3. Copy your Gumroad product link (it looks like `https://gumroad.com/l/abcxyz`).
4. Open `app.js` and replace this line near the top:

   ```js
   var GUMROAD_URL = "https://gumroad.com/l/chorechart-pro";
   ```

   with your own link.
5. Rebuild the Pro file so it contains your link too:

   ```
   node build.mjs
   ```

## Put the free tool online (free hosting)

1. Create a GitHub account at https://github.com.
2. Create a **new public repository**, e.g. `chorechart`.
3. Upload only these files: `index.html`, `styles.css`, `app.js`, `README.md`.
   **Leave out `ChoreChart-Pro.html` and `build.mjs`** — those are for you, not the public.
4. In the repo, go to **Settings → Pages → Build and deployment**, set Source to **Deploy from a branch**, choose `main` / `(root)`, and Save.
5. Your free tool is now live at `https://YOUR-USERNAME.github.io/chorechart/`.

Optional: buy a domain (Namecheap, Cloudflare, etc.) and point it at the GitHub Pages URL so it looks more professional.

## Get your first visitors

The printable-chart audience hangs out in specific places:

- **Pinterest** — create pins linking to the free tool. "free printable chore chart" is a searched phrase. This is the biggest driver for printables.
- **Facebook groups** — parenting and teacher groups often allow sharing a genuinely free tool. Read the group rules first.
- **Etsy** — a free tool can be mentioned in a shop announcement or as a bonus with a paid printable pack.
- **Reddit** — r/parenting, r/teachers, r/MiddleClassFinance — only post where self-promotion is allowed.

Add a Google Analytics or Plausible tag to `index.html` if you want to see traffic.
